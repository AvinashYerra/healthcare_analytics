# Healthcare Analytics Platform

An end-to-end healthcare analytics platform built using **PySpark, Apache Airflow, Azure Data Lake Storage, DuckDB, Streamlit, and Docker**.

This project demonstrates a modern Medallion Architecture (Bronze → Silver → Gold), orchestrated with Apache Airflow and visualized through an interactive Streamlit dashboard. It simulates a production-grade healthcare data engineering pipeline using synthetic patient data generated from **Synthea**.

---

## Features

* End-to-End Healthcare ETL Pipeline
* Medallion Architecture (Bronze → Silver → Gold)
* Config-driven dataset registry
* Generic reusable ETL framework
* Dynamic Summary Pipelines
* Apache Airflow orchestration
* Azure Data Lake Storage integration
* DuckDB analytics layer
* Interactive Streamlit dashboard
* ETL monitoring and execution metrics
* Dockerized deployment
* Modular, production-ready project structure

# Data Pipeline

## Bronze Layer

* Raw CSV files generated by Synthea
* Uploaded to Azure Data Lake
* Source of truth
* No transformations

---

## Silver Layer

Generic configurable PySpark pipelines perform:

* Schema validation
* Column standardization
* Data cleansing
* Duplicate handling
* Type casting
* Parquet generation

Each dataset is driven through a reusable Generic Pipeline.

Datasets include:

* Patients
* Providers
* Organizations
* Encounters
* Conditions

---

## Gold Layer

Business summary datasets are generated.

Current Gold tables:

* Patient Summary
* Provider Summary
* Organization Summary

Each summary pipeline inherits from a reusable Base Summary Pipeline.

---

# Airflow Workflow

The complete workflow is orchestrated using Apache Airflow.

Pipeline execution order:

```text
Upload Bronze
      │
      ▼
Bronze → Silver
      │
      ▼
Upload Silver
      │
      ▼
Silver → Gold
      │
      ▼
Upload Gold
```

Features:

* Modular Tasks
* Automatic Retry
* Execution Monitoring
* Docker Deployment
* Health Checks

---

# Azure Integration

The platform supports uploading processed datasets to Azure Data Lake Storage.

Current supported layers:

* Bronze
* Silver
* Gold

Deployment can be enabled or disabled through configuration without changing pipeline code.

---

# Analytics Layer

DuckDB is used as the analytical engine.

Benefits:

* Zero ETL loading
* Reads Parquet directly
* Extremely fast aggregation
* Lightweight
* Embedded analytics database

# Docker Deployment

Build all services

```bash
docker compose build
```

Start platform

```bash
docker compose up -d
```

Stop platform

```bash
docker compose down
```

---

# Local Development

Create virtual environment

```bash
python -m venv .venv
```

Activate

```bash
source .venv/bin/activate
```

Install packages

```bash
pip install -r requirements.txt
```

Run complete ETL

```bash
python run_orchestrator.py
```

Launch dashboard

```bash
streamlit run src/dashboard/app.py
```

Launch Airflow

```bash
docker compose up -d
```
